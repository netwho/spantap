    Bufferdrop-oldest

    A tap is never slowed down by whoever is reading it. If Wireshark cannot keep up, the oldest frames are dropped and counted — visibly — rather than blocking the receiver and pushing the loss into the kernel where nobody can see it.

    TLS

    Without TLS the token and everything this page shows cross the network in clear text. A self-signed certificate does not authenticate the server, but it does stop that.

    Off keeps plain HTTP and clears any certificate below when you save.
    Leave the key file empty if the certificate file already contains the key (a combined PEM). Uploaded files replace whatever certificate is currently set — press Save settings, then restart, same as after generating one.

    Using your own CA another way: put the leaf certificate and, if you have intermediates, the chain in one PEM file — leaf first — and either upload it above or point the Certificate field at a path readable by the user this runs as; in Docker that means a mount such as ./tls:/tls:ro and paths like /tls/cert.pem.

    Applying changes

    Shown once, right after this save — a token in here is not kept anywhere in this page after you navigate away, so copy it now if you need it.
    i Saved settings match what is running.

    Saving writes the settings; it does not move the running server. These take effect when the web UI restarts — one container:

    docker compose restart gui-lan

    Nothing else restarts. The gateway's own settings apply when you press Stop then Start on the Gateway tab, with no container restart at all — unless you run the gateway as its own container, which then needs docker compose restart gateway.

    That command restarts the existing container, which is what re-reads these settings. It is not enough after rebuilding the image: a restarted container keeps the image it was created from. To pick up new code use docker compose up -d --force-recreate instead, and check the version next to the title to confirm.

    Accounts

    a–z, 0–9, dot, dash, underscore
    length beats punctuation — use a phrase

    Everyone who can sign in can already start and stop traffic on this host, so there is no separate admin role: any account may manage accounts. The last one that can still sign in cannot be removed or disabled, so the token is never left as the only way back in. Changing or disabling an account signs that person out immediately.

    You can also do all of this on the host with spantap-sim users add|passwd|remove|list, which is how you create the first account.

    If a setting locks you out

    A command-line flag always beats the saved settings, so there is always a way back in:

    docker compose run --rm --service-ports gui gui --no-open --bind 127.0.0.1

    The server also refuses to save an address it cannot bind or a certificate it cannot load, and if a stored value stops working later it comes back on loopback rather than not at all.

    Where the frames went

    Every frame that arrived ends up in exactly one of these. If they do not add up, something is losing frames that nothing is counting — which is the one thing a tap must never do quietly.

    Connect Wireshark

    wireshark -k -i TCP@127.0.0.1:57012

    One client at a time. While nobody is attached, arriving frames are discarded rather than queued, so whoever connects sees live traffic instead of a stale backlog — those show as no client attached on the left.
